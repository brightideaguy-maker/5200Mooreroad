# 5200 Moore Road

A cinematic property website for 5200 Moore Road, Suwanee, Georgia.

## Preview

Open index.html in a browser, or run:

    python -m http.server 4173

Then visit http://localhost:4173.

## Files

- index.html: property page
- style.css: responsive layouts, typography, and motion
- app.js: gallery filters and full-screen photo story
- assets/: all 165 supplied review photographs

The page uses Google Fonts with local system font fallbacks. There is no build step or backend. Viewing enquiries link to the Zillow listing.

Property details were reviewed against the supplied Zillow listing on October 20, 2026. The supplied review photos are low resolution; original-resolution images are recommended for full-screen presentation.
